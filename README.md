# Project page (GitHub Pages)

This repo is a simple static site (pure HTML + CSS + a tiny JS file).

## How to publish

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. In **Build and deployment**, choose:
   - Source: *Deploy from a branch*
   - Branch: *main*
   - Folder: */ (root)*
4. Wait for GitHub to give you the website link.

## What to edit

- `index.html`: all your text, links, and section structure
- `project.css`: main styles
- `img/*.png`: your figures
- `paper.png`, `code.png`, `icon_github.png`: icons for the three cards
